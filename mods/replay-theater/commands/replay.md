# /replay

Executa a auditoria interativa de alterações e exibe os diffs com destaque de sintaxe no terminal.

```bash
# Execução direta:
# /replay
```

Mostra todos os arquivos editados pelas ferramentas durante os turnos recentes e executa a comparação de código com destaque ANSI verde/vermelho.
